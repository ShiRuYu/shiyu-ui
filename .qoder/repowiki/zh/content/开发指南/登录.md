# 登录

> 官方文档：https://doc.vben.pro/guide/in-depth/login.html

## 登录页面调整

### 调整登录页布局（标题/描述/工具栏）

在应用的 `src/layouts/auth.vue` 中配置 `AuthPageLayout` 组件：

```vue
<AuthPageLayout
  :copyright="true"
  :toolbar="true"
  :toolbarList="['color', 'language', 'layout', 'theme']"
  :app-name="appName"
  :logo="logo"
  :page-description="$t('authentication.pageDesc')"
  :page-title="$t('authentication.pageTitle')"
/>
```

### 调整登录表单

在 `src/views/_core/authentication/login.vue` 中配置 `AuthenticationLogin` 组件：

```vue
<AuthenticationLogin
  :loading="authStore.loginLoading"
  @submit="authStore.authLogin"
/>
```

#### AuthenticationLogin 参数

| 参数                  | 类型      | 说明               |
| --------------------- | --------- | ------------------ |
| `loading`             | `boolean` | 是否处于加载中状态 |
| `codeLoginPath`       | `string`  | 验证码登录路径     |
| `forgetPasswordPath`  | `string`  | 忘记密码路径       |
| `qrCodeLoginPath`     | `string`  | 二维码登录路径     |
| `registerPath`        | `string`  | 注册路径           |
| `showCodeLogin`       | `boolean` | 显示验证码登录     |
| `showForgetPassword`  | `boolean` | 显示忘记密码       |
| `showQrcodeLogin`     | `boolean` | 显示二维码登录     |
| `showRegister`        | `boolean` | 显示注册按钮       |
| `showRememberMe`      | `boolean` | 显示记住账号       |
| `showThirdPartyLogin` | `boolean` | 显示第三方登录     |
| `subTitle`            | `string`  | 登录框副标题       |
| `title`               | `string`  | 登录框标题         |

## 接口对接流程

### 前置条件

**1. 接口返回格式统一为：**

```ts
interface HttpResponse<T = any> {
  code: number; // 0 表示成功
  data: T;
  message: string;
}
```

如果不符合此格式，需先修改 `src/api/request.ts` 中的 `defaultResponseInterceptor` 配置。

**2. 修改代理地址为真实后端：**

```ts
// apps/web-naive/vite.config.ts
proxy: {
  '/api': {
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/api/, ''),
    target: 'http://your-backend.com/api',  // 改为真实地址
    ws: true,
  },
},
```

### 登录接口（必须）

接口位于 `src/api/core/auth.ts`：

```ts
export async function loginApi(data: AuthApi.LoginParams) {
  return requestClient.post<AuthApi.LoginResult>('/auth/login', data);
}

// 接口返回值必须包含 accessToken 字段
export interface LoginResult {
  accessToken: string;
}
```

### 获取用户信息接口（必须）

接口位于 `src/api/core/user.ts`：

```ts
export async function getUserInfoApi() {
  return requestClient.get<UserInfo>('/user/info');
}

// 接口返回值必须包含以下字段
export interface UserInfo {
  roles: string[]; // 用户角色（用于权限控制）
  realName: string; // 用户名
}
```

### 获取权限码接口（可选）

接口位于 `src/api/core/auth.ts`：

```ts
export async function getAccessCodesApi() {
  return requestClient.get<string[]>('/auth/codes');
}

// 不需要权限码时，直接返回空数组
export async function getAccessCodesApi() {
  return [];
}
```

### 对接步骤总结

1. 确认后端接口返回格式（`code/data/message`）
2. 修改 `vite.config.ts` 代理到真实后端
3. 修改 `src/api/core/auth.ts` 中的登录接口地址
4. 修改 `src/api/core/user.ts` 中的用户信息接口地址
5. 确保 `getUserInfoApi` 返回包含 `roles` 字段
6. 如需按钮权限，确保 `getAccessCodesApi` 返回权限码数组
