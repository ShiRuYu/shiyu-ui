# 基础概念

> 官方文档：https://doc.vben.pro/guide/essentials/concept.html

新版本中，整体工程进行了重构。本文介绍一些基础概念，以便于更好地理解整个框架结构。

## 大仓（Monorepo）

大仓指的是整个项目的仓库，包含了所有的代码、包、应用、规范、文档、配置等，也就是一整个 Monorepo 目录的所有内容。

## 应用（App）

应用指的是一个完整的项目，一个大仓可以包含多个应用，这些应用可以复用大仓内的代码、包、规范等。应用都被放置在 `apps/` 目录下，每个应用都是独立的，可以单独运行、构建、测试、部署，可以引入不同的组件库。

| 应用                | 说明                          |
| ------------------- | ----------------------------- |
| `apps/web-naive`    | Naive UI 版本（本项目主应用） |
| `playground`        | Ant Design Vue 参考示例       |
| `apps/backend-mock` | Nitro Mock 后端服务           |

## 包（Package）

包指的是一个独立的模块，可以是一个组件、工具、库等。包可以被多个应用引用，也可以被其他包引用。包都被放置在 `packages/` 目录下。

### 包引入

在 `package.json` 中引入包：

```json
{
  "dependencies": {
    "@vben/utils": "workspace:*"
  }
}
```

### 包使用

在代码中引入包：

```ts
import { isString } from '@vben/utils';
```

## 别名（# 路径）

在项目中，可以看到一些 `#` 开头的路径，例如：`#/api`、`#/views`，这些路径都是别名，用于快速定位到某个目录。它通过 Node.js 本身的 `subpath imports` 原理实现，而不是 Vite 的 `alias`。

在 `package.json` 中配置 `imports` 字段：

```json
{
  "imports": {
    "#/*": "./src/*"
  }
}
```

在 `tsconfig.json` 中配置以支持 IDE 识别：

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "#/*": ["src/*"]
    }
  }
}
```

## 目录结构速览

```
.
├── apps/           # 各应用目录
│   ├── web-naive/  # Naive UI 主应用（本项目）
│   └── backend-mock/
├── packages/       # 公共包
│   ├── @core/      # 核心包
│   ├── effects/    # 副作用包（hooks、stores 等）
│   ├── ui-kit/     # UI 工具包
│   └── ...
├── internal/       # 内部工具（构建配置、lint 等）
└── scripts/        # 脚本工具
```
