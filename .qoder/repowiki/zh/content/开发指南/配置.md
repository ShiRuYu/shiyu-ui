# 配置

> 官方文档：https://doc.vben.pro/guide/essentials/settings.html

## 环境变量配置

项目的环境变量配置位于应用目录下的 `.env`、`.env.development`、`.env.production`。

```bash
.env                # 所有环境载入
.env.local          # 所有环境载入，但被 git 忽略
.env.[mode]         # 只在指定模式中载入
.env.[mode].local   # 只在指定模式中载入，但被 git 忽略
```

> 只有以 `VITE_` 开头的变量会被嵌入客户端包。以 `VITE_GLOB_*` 开头的变量，打包时会加入 `_app.config.js`。

### 常用环境变量

| 变量 | 文件 | 说明 |
| --- | --- | --- |
| `VITE_APP_TITLE` | `.env` | 应用标题 |
| `VITE_APP_NAMESPACE` | `.env` | 应用命名空间（缓存前缀） |
| `VITE_PORT` | `.env.development` | 开发服务器端口（默认 5555） |
| `VITE_BASE` | `.env` | 资源公共路径（以 `/` 开头和结尾） |
| `VITE_GLOB_API_URL` | `.env.*` | 接口地址 |
| `VITE_NITRO_MOCK` | `.env.development` | 是否开启 Nitro Mock 服务 |
| `VITE_DEVTOOLS` | `.env.development` | 是否开启 Vue DevTools |
| `VITE_INJECT_APP_LOADING` | `.env.*` | 是否注入全局 loading |
| `VITE_COMPRESS` | `.env.production` | 压缩方式（none/gzip/brotli） |
| `VITE_PWA` | `.env.production` | 是否开启 PWA |
| `VITE_ROUTER_HISTORY` | `.env.production` | 路由模式（hash/history） |
| `VITE_ARCHIVER` | `.env.production` | 打包后是否生成 dist.zip |

## 生产环境动态配置

构建后会在 `dist/_app.config.js` 中生成动态配置文件，无需重新打包即可修改接口地址：

```js
window._VBEN_ADMIN_PRO_APP_CONF_ = {
  VITE_GLOB_API_URL: 'https://your-api.com/api',
};
```

### 读取动态配置

```ts
import { useAppConfig } from '@vben/hooks';

const { apiURL } = useAppConfig(import.meta.env, import.meta.env.PROD);
```

### 新增动态配置项

1. 在 `.env` 中新增 `VITE_GLOB_*` 变量
2. 在 `packages/types/global.d.ts` 中新增类型定义
3. 在 `packages/effects/hooks/src/use-app-config.ts` 中新增对应配置项

## 偏好设置

配置文件位于应用目录下的 `preferences.ts`，通过 `defineOverridesPreferences` 覆盖框架默认配置：

```ts
import { defineOverridesPreferences } from '@vben/preferences';

export const overridesPreferences = defineOverridesPreferences({
  app: {
    name: import.meta.env.VITE_APP_TITLE,
    // 权限模式：frontend | backend | mixed
    accessMode: 'frontend',
    // 登录过期处理：page | modal
    loginExpiredMode: 'modal',
    // 开启刷新 Token
    enableRefreshToken: false,
    // 默认首页路径
    defaultHomePath: '/dashboard',
  },
  theme: {
    // 主题色（hsl 格式）
    colorPrimary: 'hsl(212 100% 45%)',
    // 内置主题类型
    builtinType: 'default',
  },
});
```

### 扩展项目级偏好

除了覆盖框架内置偏好外，还可以为应用追加一组业务偏好：

```ts
import { definePreferencesExtension } from '@vben/preferences';

export const preferencesExtension = definePreferencesExtension<ProjectPrefs>({
  tabLabel: 'preferences.project.tabLabel',
  title: 'preferences.project.title',
  fields: [
    {
      component: 'switch', // input | number | select | switch
      defaultValue: true,
      key: 'enableFormFullscreen',
      label: 'preferences.project.fields.enableFormFullscreen.label',
    },
    {
      component: 'select',
      defaultValue: 'single',
      key: 'tenantMode',
      label: 'preferences.project.fields.tenantMode.label',
      options: [
        { label: 'single', value: 'single' },
        { label: 'multi', value: 'multi' },
      ],
    },
  ],
});
```

初始化时传入：

```ts
await initPreferences({
  namespace,
  overrides: overridesPreferences,
  extension: preferencesExtension,
});
```

读取/更新扩展偏好：

```ts
import {
  getCustomPreferences,
  updateCustomPreferences,
} from '@vben/preferences';

const prefs = getCustomPreferences<ProjectPrefs>();
updateCustomPreferences<ProjectPrefs>({ tenantMode: 'multi' });
```

> 注意：更改偏好设置后请清空缓存，否则可能不生效。

## 框架默认配置概览

| 配置项                   | 默认值         | 说明           |
| ------------------------ | -------------- | -------------- |
| `app.accessMode`         | `'frontend'`   | 权限模式       |
| `app.loginExpiredMode`   | `'modal'`      | 登录过期处理   |
| `app.enableRefreshToken` | `false`        | 自动刷新 Token |
| `app.dynamicTitle`       | `true`         | 动态网页标题   |
| `app.enableCheckUpdates` | `true`         | 检查更新       |
| `app.defaultHomePath`    | `'/analytics'` | 默认首页       |
| `theme.builtinType`      | `'default'`    | 内置主题       |
