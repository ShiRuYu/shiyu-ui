# 常用功能

> 官方文档：https://doc.vben.pro/guide/in-depth/features.html

## 登录认证过期处理

当接口返回 401 状态码时，框架会认为登录认证过期。可配置两种处理方式：

### 跳转登录页面

```ts
// preferences.ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    loginExpiredMode: 'page', // 登录超时跳转到登录页
  },
});
```

### 打开登录弹窗

```ts
// preferences.ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    loginExpiredMode: 'modal', // 登录超时弹出登录弹窗
  },
});
```

## 动态标题

开启后网页标题随路由 `meta.title` 变化（默认开启）：

```ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    dynamicTitle: true,
  },
});
```

## 页面水印

```ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    watermark: true, // 默认关闭
  },
});
```

更新水印内容：

```ts
import { useWatermark } from '@vben/hooks';

const { destroyWatermark, updateWatermark } = useWatermark();

// 更新水印
await updateWatermark({
  content: '内部专用 - 张三', // 水印文字
});

// 移除水印
destroyWatermark();
```

> 水印参数可参考 [watermark-js-plus](https://github.com/zhensherlock/watermark-js-plus) 文档。

## 检查更新

框架内置了检查更新机制，默认开启，定时检查是否有新版本发布：

```ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    enableCheckUpdates: true, // 开启检查更新
    checkUpdatesInterval: 1, // 检查间隔（分钟）
  },
});
```

## 偏好设置面板

框架内置了偏好设置面板，允许用户在运行时调整布局、主题等设置（默认开启）：

```ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    enablePreferences: true, // 开启偏好设置面板
    enableCopyPreferences: true, // 开启复制偏好设置
  },
});
```

## 常用 Hooks

### useAppConfig — 获取应用配置

```ts
import { useAppConfig } from '@vben/hooks';

const { apiURL } = useAppConfig(import.meta.env, import.meta.env.PROD);
```

### useAccess — 权限判断

```ts
import { useAccess } from '@vben/access';

const { hasAccessByCodes, hasAccessByRoles, accessMode } = useAccess();

// 判断是否有权限码
const canEdit = hasAccessByCodes(['AC_EDIT']);

// 判断是否有角色
const isAdmin = hasAccessByRoles(['admin']);
```

### usePreferences — 获取/修改偏好

```ts
import { usePreferences } from '@vben/preferences';

const { preferences, updatePreferences } = usePreferences();

// 切换暗色模式
updatePreferences({ theme: { mode: 'dark' } });
```

### useWatermark — 水印控制

```ts
import { useWatermark } from '@vben/hooks';

const { updateWatermark, destroyWatermark } = useWatermark();
```
