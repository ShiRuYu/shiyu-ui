# 图标

> 官方文档：https://doc.vben.pro/guide/essentials/icons.html

项目中的图标主要由 `@vben/icons` 包提供，建议统一在该包内部管理，便于统一维护。

推荐安装 VSCode 插件 **Iconify IntelliSense**，可方便查找和使用图标。

## 三种图标使用方式

### 1. Iconify 图标（推荐）

集成了 iconify 图标库，可使用海量图标集。

#### 新增图标

在 `packages/icons/src/iconify/index.ts` 中注册：

```ts
import { createIconifyIcon } from '@vben-core/icons';

export const MdiKeyboardEsc = createIconifyIcon('mdi:keyboard-esc');
export const LucideUser = createIconifyIcon('lucide:user');
```

#### 使用图标

```vue
<script setup lang="ts">
import { MdiKeyboardEsc, LucideUser } from '@vben/icons';
</script>

<template>
  <!-- 宽高为 20px 的图标 -->
  <MdiKeyboardEsc class="size-5" />
  <LucideUser class="size-5" />
</template>
```

### 2. SVG 图标（推荐）

直接引入本地 SVG 文件，不依赖网络，适合自定义图标。

#### 新增 SVG 图标

1. 在 `packages/icons/src/svg/icons/` 目录下放入 SVG 文件，如 `my-icon.svg`
2. 在 `packages/icons/src/svg/index.ts` 中导出：

```ts
import { createIconifyIcon } from '@vben-core/icons';

export const SvgMyIcon = createIconifyIcon('svg:my-icon');
```

#### 使用 SVG 图标

```vue
<script setup lang="ts">
import { SvgMyIcon } from '@vben/icons';
</script>

<template>
  <SvgMyIcon class="size-5" />
</template>
```

### 3. Tailwind CSS 图标

直接使用 Tailwind CSS 类名，无需导入：

```vue
<template>
  <span class="icon-[mdi--home]"></span>
  <span class="icon-[lucide--user]"></span>
</template>
```

图标类名格式为 `icon-[集合名--图标名]`，可在 [Iconify 官网](https://icon-sets.iconify.design/) 查找。

## 在路由 Meta 中使用图标

```ts
{
  meta: {
    icon: 'lucide:home',          // Iconify 图标名称
    // 或
    icon: 'https://example.com/icon.png',  // HTTP 链接图片
  }
}
```

## 常用图标集

| 图标集                | 前缀          | 说明          |
| --------------------- | ------------- | ------------- |
| Lucide                | `lucide:`     | 简洁线条图标  |
| Material Design Icons | `mdi:`        | Material 图标 |
| Iconify               | `ic:`         | 通用图标集    |
| Ant Design            | `ant-design:` | AntD 图标     |
