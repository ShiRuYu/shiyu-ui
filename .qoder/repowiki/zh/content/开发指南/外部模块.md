# 外部模块

> 官方文档：https://doc.vben.pro/guide/essentials/external-module.html

除了项目默认引入的模块，有时需要引入其他外部 npm 包。

## 安装依赖

由于项目采用 Pnpm + Monorepo，需要在**指定包目录**下安装依赖：

```bash
# 先进入对应应用目录
cd apps/web-naive
# 安装依赖
pnpm add some-package

# 或者从根目录使用 --filter 参数
pnpm add some-package --filter @vben/web-naive
```

## 使用方式

### 全局引入

在应用的 `src/main.ts` 或 `src/bootstrap.ts` 中全局注册：

```ts
import { createApp } from 'vue';
import SomePlugin from 'some-package';
import 'some-package/dist/style.css'; // 如有样式需要引入

const app = createApp(App);
app.use(SomePlugin).mount('#app');
```

### 局部引入（推荐）

在需要使用的组件中按需引入：

```vue
<script setup lang="ts">
import { SomeComponent } from 'some-package';
import 'some-package/dist/style.css'; // 如有依赖样式
</script>

<template>
  <SomeComponent />
</template>
```

> 注意：如果组件有依赖样式，需要在引入组件的同时引入样式文件。

## 常见场景

### 引入图表库（ECharts）

```bash
pnpm add echarts --filter @vben/web-naive
```

```vue
<script setup lang="ts">
import * as echarts from 'echarts';
import { onMounted, ref } from 'vue';

const chartRef = ref<HTMLElement>();

onMounted(() => {
  const chart = echarts.init(chartRef.value!);
  chart.setOption({
    /* ... */
  });
});
</script>
<template>
  <div ref="chartRef" class="h-64 w-full"></div>
</template>
```

### 引入工具库

```bash
pnpm add dayjs --filter @vben/web-naive
```

```ts
import dayjs from 'dayjs';
const today = dayjs().format('YYYY-MM-DD');
```
