# 构建与部署

> 官方文档：https://doc.vben.pro/guide/essentials/build.html

## 构建

在项目根目录下执行：

```bash
pnpm build
```

构建成功后，会在对应的应用下生成 `dist/` 文件夹，例如 `apps/web-naive/dist/`。

## 预览构建结果

```bash
# 方式一：项目内置命令（推荐）
pnpm preview

# 方式二：使用 live-server
npm i -g live-server
cd apps/web-naive/dist
live-server --port=9000
```

## 压缩配置

在 `.env.production` 中配置：

```bash
# 开启 gzip
VITE_COMPRESS=gzip

# 开启 brotli
VITE_COMPRESS=brotli

# 同时开启 gzip 和 brotli
VITE_COMPRESS=gzip,brotli

# 不压缩
VITE_COMPRESS=none
```

Nginx 压缩配置示例：

```nginx
http {
  gzip on;
  gzip_static on;
  gzip_min_length 1k;
  gzip_comp_level 2;
  gzip_types text/plain application/javascript text/css application/xml text/javascript;

  brotli on;
  brotli_comp_level 6;
  brotli_min_length 20;
  brotli_types text/plain text/css application/json application/javascript;
}
```

## 部署

将 `dist/` 目录下的文件部署到 CDN 或静态服务器。

### Nginx 配置示例

```nginx
server {
  listen 80;

  location / {
    # 不缓存 html
    if ($request_filename ~* .*\.(?:htm|html)$) {
      add_header Cache-Control "private, no-store, no-cache, must-revalidate, proxy-revalidate";
    }
    root   /srv/www/project/;
    index  index.html index.htm;
  }
}
```

### history 路由模式配置

```nginx
# 部署到根目录
server {
  listen 80;
  location / {
    try_files $uri $uri/ /index.html;
  }
}

# 部署到子目录（需同时设置 VITE_BASE=/sub/）
server {
  location /sub/ {
    alias /srv/www/project/;
    index index.html;
    try_files $uri $uri/ /sub/index.html;
  }
}
```

### hash 路由模式（默认）

在 `.env.production` 中配置：

```bash
VITE_ROUTER_HISTORY=hash
```

hash 路由无需特殊 Nginx 配置。

## 资源路径配置

如果部署后资源路径不正确，修改 `.env.production`：

```bash
# 部署到根目录
VITE_BASE=/

# 部署到子路径
VITE_BASE=/my-app/
```

## 跨域处理

### 生产环境 Nginx 代理

```bash
# .env.production
VITE_GLOB_API_URL=/api
```

```nginx
server {
  listen 8080;

  location /api {
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_pass http://your-backend.com:8080/api;
    rewrite "^/api/(.*)$" /$1 break;
    add_header Access-Control-Allow-Origin *;
    add_header Access-Control-Allow-Methods GET,POST,OPTIONS;
  }
}
```

## Docker 部署

项目提供了 Docker 构建脚本：

```bash
# 构建本地 Docker 镜像
pnpm build:docker
```

Dockerfile 位于 `scripts/deploy/Dockerfile`，Nginx 配置位于 `scripts/deploy/nginx.conf`。
