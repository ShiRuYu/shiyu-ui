# 路由和菜单

> 官方文档：https://doc.vben.pro/guide/essentials/route.html

框架提供了一套基础的路由系统，并根据路由文件自动生成对应的菜单结构。

## 路由类型

| 类型     | 说明                             | 路径                         |
| -------- | -------------------------------- | ---------------------------- |
| 核心路由 | 框架内置（根路由、登录、404 等） | `src/router/routes/core/`    |
| 静态路由 | 项目启动时确定的路由             | `src/router/routes/static/`  |
| 动态路由 | 用户登录后根据权限动态生成       | `src/router/routes/modules/` |

> 静态路由与动态路由都会走权限控制，通过路由 `meta.authority` 字段控制访问权限。

## 路由定义

### 二级路由示例

```ts
import type { RouteRecordRaw } from 'vue-router';
import { $t } from '#/locales';

const routes: RouteRecordRaw[] = [
  {
    meta: {
      icon: 'mdi:home',
      title: $t('page.home.title'),
    },
    name: 'Home',
    path: '/home',
    redirect: '/home/index',
    children: [
      {
        name: 'HomeIndex',
        path: '/home/index',
        component: () => import('#/views/home/index.vue'),
        meta: {
          icon: 'mdi:home',
          title: $t('page.home.index'),
        },
      },
    ],
  },
];

export default routes;
```

### 多级路由示例

```ts
const routes: RouteRecordRaw[] = [
  {
    meta: { icon: 'ic:baseline-view-in-ar', order: 1000, title: '演示' },
    name: 'Demos',
    path: '/demos',
    children: [
      {
        meta: { icon: 'ic:round-menu', title: '嵌套菜单' },
        name: 'NestedDemos',
        path: '/demos/nested',
        children: [
          {
            name: 'Menu1Demo',
            path: '/demos/nested/menu1',
            component: () => import('#/views/demos/nested/menu-1.vue'),
            meta: { keepAlive: true, title: 'Menu1' },
          },
        ],
      },
    ],
  },
];
```

## 新增页面

1. 在 `src/router/routes/modules/` 或 `static/` 下新建或修改路由文件，添加路由对象
2. 在 `#/views/` 对应目录下创建页面组件 `.vue` 文件
3. 访问对应路径验证

## 路由 Meta 配置完整类型

```ts
interface RouteMeta {
  /** 激活图标（菜单） */
  activeIcon?: string;
  /** 当前激活的菜单路径（用于激活父级菜单） */
  activePath?: string;
  /** 是否固定标签页 @default false */
  affixTab?: boolean;
  /** 固定标签页的顺序 @default 0 */
  affixTabOrder?: number;
  /** 需要特定的角色才可以访问 @default [] */
  authority?: string[];
  /** 徽标内容 */
  badge?: string;
  /** 徽标类型 */
  badgeType?: 'dot' | 'normal';
  /** 徽标颜色 */
  badgeVariants?:
    | 'default'
    | 'destructive'
    | 'primary'
    | 'success'
    | 'warning'
    | string;
  /** 路由的完整路径作为 key @default true */
  fullPathKey?: boolean;
  /** 子级在菜单中不展现 @default false */
  hideChildrenInMenu?: boolean;
  /** 在面包屑中不展现 @default false */
  hideInBreadcrumb?: boolean;
  /** 在菜单中不展现 @default false */
  hideInMenu?: boolean;
  /** 在标签页中不展现 @default false */
  hideInTab?: boolean;
  /** 图标（菜单/tab） */
  icon?: string;
  /** iframe 地址 */
  iframeSrc?: string;
  /** 忽略权限，直接可以访问 @default false */
  ignoreAccess?: boolean;
  /** 开启 KeepAlive 缓存 */
  keepAlive?: boolean;
  /** 外链跳转路径 */
  link?: string;
  /** 标签页最大打开数量 @default false */
  maxNumOfOpenTab?: number;
  /** 菜单可见但访问重定向到403 */
  menuVisibleWithForbidden?: boolean;
  /** 不使用基础布局（仅顶级生效） */
  noBasicLayout?: boolean;
  /** 在新窗口打开 */
  openInNewWindow?: boolean;
  /** 菜单排序 */
  order?: number;
  /** 菜单所携带的参数 */
  query?: Recordable;
  /** 标题名称（必填） */
  title: string;
}
```

## 常用 Meta 字段说明

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | - | 页面标题，显示在菜单/标签页中（必填） |
| `icon` | `string` | - | 页面图标，支持 http 链接 |
| `authority` | `string[]` | `[]` | 权限控制，不配置则不需要权限 |
| `keepAlive` | `boolean` | `false` | 开启页面缓存（需配合标签页使用） |
| `hideInMenu` | `boolean` | `false` | 在菜单中隐藏 |
| `hideInTab` | `boolean` | `false` | 在标签页中隐藏 |
| `hideInBreadcrumb` | `boolean` | `false` | 在面包屑中隐藏 |
| `hideChildrenInMenu` | `boolean` | `false` | 子页面在菜单中隐藏 |
| `order` | `number` | - | 菜单排序，数值越小越靠前 |
| `affixTab` | `boolean` | `false` | 固定标签页 |
| `noBasicLayout` | `boolean` | `false` | 不使用框架布局（全屏页面用） |
| `iframeSrc` | `string` | - | 内嵌 iframe 地址 |
| `link` | `string` | - | 外链跳转地址 |
| `menuVisibleWithForbidden` | `boolean` | `false` | 菜单可见但无权限时跳 403 |
| `ignoreAccess` | `boolean` | `false` | 忽略权限控制，直接可访问 |
