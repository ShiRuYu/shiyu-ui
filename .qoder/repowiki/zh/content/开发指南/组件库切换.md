# 组件库切换

> 官方文档：https://doc.vben.pro/guide/in-depth/ui-framework.html

Vben Admin 支持自由切换组件库。演示站点默认使用 **Ant Design Vue**，同时内置了 **Element Plus** 和 **Naive UI** 版本，可根据项目需求自由选择。

---

## 当前项目使用的组件库

本项目基于 **Naive UI** 应用（`apps/web-naive`），对应适配器位于 `apps/web-naive/src/adapter/`，负责将 Naive UI 组件注册到 VbenForm、VbenModal、VbenDrawer 等通用组件中。

---

## 新增其他组件库应用

如果要接入全新的组件库（例如 Vuetify、PrimeVue 等），按以下步骤操作：

### 步骤

1. **在 `apps/` 下创建新应用文件夹**，例如 `apps/web-xxx`。
2. **修改 `package.json` 的 name 字段**为 `web-xxx`。
3. **移除原有组件库依赖**，安装新组件库，并修改适配器（`src/adapter/`）中的组件注册逻辑。
4. **调整 `locales/`** 内的语言文件，确保国际化匹配。
5. **调整 `app.vue`** 内的根组件引入（如组件库的全局配置提供者）。
6. **适配主题**：将组件库的主题色变量与 Vben Admin 的 CSS 变量体系进行对齐（参考 `开发指南/主题.md`）。
7. **修改 `.env`** 内的应用名称 `VITE_APP_TITLE`。
8. **在根 `package.json`** 中新增 `dev:xxx` 和 `build:xxx` 脚本。
9. 执行 `pnpm install` 安装依赖。

## 核心适配文件

每个应用都需要实现以下适配逻辑：

```
apps/web-xxx/src/adapter/
├── component.ts   # 注册 UI 组件到 VbenForm 等通用组件（ComponentType 类型声明 + 组件映射）
├── form.ts        # 调用 setupVbenForm，配置 baseModelPropName、emptyStateValue 等
└── vxe-table.ts   # 调用 setupVbenVxeTable，配置 vxe-grid 默认行为和自定义渲染器
```

### 适配器关键配置（以 Naive UI 为例）

**`form.ts`**：

```ts
setupVbenForm<ComponentType>({
  config: {
    baseModelPropName: 'value', // Naive UI 默认使用 v-model:value
    emptyStateValue: null,
    modelPropNameMap: {
      Checkbox: 'checked',
      Switch: 'checked',
    },
  },
  defineRules: {
    required: (value, _params, ctx) => {
      if (value === undefined || value === null || value.length === 0) {
        return $t('ui.formRules.required', [ctx.label]);
      }
      return true;
    },
    selectRequired: (value, _params, ctx) => {
      if (value === undefined || value === null) {
        return $t('ui.formRules.selectRequired', [ctx.label]);
      }
      return true;
    },
  },
});
```

**`component.ts`**（关键片段）：

```ts
export type ComponentType =
  | 'AutoComplete'
  | 'Checkbox'
  | 'DatePicker'
  | 'Input'
  | 'InputNumber'
  | 'Select'
  | 'Switch'
  | 'TreeSelect'
  | BaseFormComponentType; // 来自 @vben/common-ui，包含 Divider、Space 等基础类型

async function initComponentAdapter() {
  const components: Partial<Record<ComponentType, Component>> = {
    Input: withDefaultPlaceholder(NInput, 'input'),
    Select: withDefaultPlaceholder(NSelect, 'select'),
    Switch: NSwitch,
    // ... 其他组件
  };
  globalShareState.setComponents(components);
}
```

---

## 注意事项

- 适配器改动通常集中在 `src/adapter/` 目录，**不需要修改** `@vben/common-ui` 包本身。
- 主题适配是工作量最大的部分，需要将组件库的设计 token 与 Vben Admin 的 CSS 变量（`--primary`、`--background` 等）对齐，详见 `开发指南/主题.md`。
- 三个内置版本（Ant Design Vue / Element Plus / Naive UI）的适配器代码可作为参考实现。
