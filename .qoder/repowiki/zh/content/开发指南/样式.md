# 样式

> 官方文档：https://doc.vben.pro/guide/essentials/styles.html

## 项目结构

项目中的样式文件存放在 `@vben/styles` 包中，包含全局样式（重置样式、全局变量等）。它继承了 `@vben-core/design` 的样式和能力，可根据项目需求进行覆盖。

## 四种样式方案

### 1. Tailwind CSS（推荐）

项目集成了 Tailwind CSS，可以直接使用原子类名构建页面：

```vue
<template>
  <div class="bg-white p-4 rounded-lg shadow">
    <p class="text-green-500 text-sm">hello world</p>
  </div>
</template>
```

### 2. Scss

项目使用 scss 作为样式预处理器：

```vue
<style lang="scss" scoped>
$font-size: 30px;

.box {
  .title {
    color: green;
    font-size: $font-size;
  }
}
</style>
```

### 3. PostCSS（CSS 嵌套）

内置了 `postcss-nested` 插件，完全可以取代 scss：

```vue
<style scoped>
.box {
  --font-size: 30px;
  .title {
    color: green;
    font-size: var(--font-size);
  }
}
</style>
```

### 4. CSS Modules

针对样式隔离场景：

```vue
<template>
  <p :class="$style.red">This should be red</p>
</template>

<style module>
.red {
  color: red;
}
</style>
```

## BEM 规范

如果选择 Scss，建议使用 BEM 命名规范。项目默认提供了 `useNamespace` 函数：

```vue
<script lang="ts" setup>
import { useNamespace } from '@vben/hooks';

const { b, e, is } = useNamespace('menu');
</script>
<template>
  <div :class="[b()]">
    <div :class="[e('item'), is('active', true)]">item1</div>
  </div>
</template>
<style lang="scss" scoped>
// 如果在应用内使用，这行可省略（已全局引入）
@use '@vben/styles/global' as *;

@include b('menu') {
  color: black;

  @include e('item') {
    background-color: white;

    @include is('active') {
      background-color: #1890ff;
    }
  }
}
</style>
```

## CSS 变量（主题变量）

框架基于 shadcn-vue 约定使用 CSS 变量管理主题颜色，颜色值使用 HSL 格式：

```html
<!-- 背景使用 --background，前景（文字）使用 --foreground -->
<div class="bg-background text-foreground"></div>
```

主要 CSS 变量：

| 变量           | 说明          |
| -------------- | ------------- |
| `--background` | 页面背景色    |
| `--foreground` | 主要文字颜色  |
| `--primary`    | 主题色        |
| `--secondary`  | 次要颜色      |
| `--muted`      | 静默/弱化颜色 |
| `--border`     | 边框颜色      |
| `--card`       | 卡片背景色    |
| `--sidebar`    | 侧边栏背景色  |
| `--header`     | 顶部栏背景色  |

> 覆盖 CSS 变量时必须使用 HSL 格式（如 `212 100% 45%`），不需要加 `hsl()` 和括号。
