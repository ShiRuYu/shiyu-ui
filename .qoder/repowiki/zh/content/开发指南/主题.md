# 主题

> 官方文档：https://doc.vben.pro/guide/in-depth/theme.html

框架基于 shadcn-vue 和 Tailwind CSS 构建，提供丰富的主题配置，支持亮色/暗色模式和多种内置主题。

## CSS 变量约定

框架遵循 shadcn-vue 的主题约定，使用 CSS 变量管理颜色：

- `background` 变量用于组件背景色
- `foreground` 变量用于文字颜色

```html
<div class="bg-background text-foreground" />
<div class="bg-primary text-primary-foreground" />
```

> **重要**：CSS 变量颜色必须使用 HSL 格式（如 `212 100% 45%`），不需要加 `hsl()` 和括号。

## 主要 CSS 变量

### 亮色模式（`:root`）

| 变量                   | 默认值              | 说明           |
| ---------------------- | ------------------- | -------------- |
| `--background`         | `0 0% 100%`         | 页面背景色     |
| `--background-deep`    | `216 20.11% 95.47%` | 主体区域背景色 |
| `--foreground`         | `210 6% 21%`        | 主要文字颜色   |
| `--primary`            | `212 100% 45%`      | 主题色         |
| `--primary-foreground` | `0 0% 98%`          | 主题色上的文字 |
| `--secondary`          | `240 5% 96%`        | 次要颜色       |
| `--muted`              | `210 40% 96.1%`     | 弱化颜色       |
| `--border`             | `240 5.9% 90%`      | 边框颜色       |
| `--card`               | `0 0% 100%`         | 卡片背景色     |
| `--sidebar`            | `0 0% 100%`         | 侧边栏背景色   |
| `--header`             | `0 0% 100%`         | 顶部栏背景色   |
| `--destructive`        | `0 78% 68%`         | 错误/危险色    |
| `--success`            | `144 57% 58%`       | 成功色         |
| `--warning`            | `42 84% 61%`        | 警告色         |
| `--radius`             | `0.5rem`            | 圆角大小       |

### 暗色模式（`.dark`）

暗色模式通过 `.dark` class 激活，覆盖对应的 CSS 变量。

## 覆盖 CSS 变量

在项目的全局 CSS 文件中覆盖：

```css
/* 亮色模式 */
:root {
  --card: 0 0% 30%;
  --radius: 0.75rem;
}

/* 暗色模式 */
.dark,
.dark[data-theme='custom'],
.dark[data-theme='default'] {
  --card: 222.34deg 10.43% 12.27%;
}
```

## 更改品牌主色

在应用目录的 `preferences.ts` 中配置：

```ts
import { defineOverridesPreferences } from '@vben/preferences';

export const overridesPreferences = defineOverridesPreferences({
  theme: {
    colorPrimary: 'hsl(212 100% 45%)', // 主题色
    colorDestructive: 'hsl(348 100% 61%)', // 错误色
    colorSuccess: 'hsl(144 57% 58%)', // 成功色
    colorWarning: 'hsl(42 84% 61%)', // 警告色
  },
});
```

> 修改后需要清空浏览器缓存才可生效。可借助第三方工具将 HEX 颜色转换为 HSL 格式。

## 内置主题

框架内置了 16 种主题，在 `preferences.ts` 中配置：

```ts
export const overridesPreferences = defineOverridesPreferences({
  theme: {
    builtinType: 'default',
  },
});
```

### 内置主题列表

```ts
type BuiltinThemeType =
  | 'custom' // 自定义主题
  | 'deep-blue'
  | 'deep-green'
  | 'default' // 默认主题（蓝色）
  | 'gray'
  | 'green'
  | 'neutral'
  | 'orange'
  | 'pink'
  | 'red'
  | 'rose'
  | 'sky-blue'
  | 'slate'
  | 'stone'
  | 'violet'
  | 'yellow'
  | 'zinc'
  | (Record<never, never> & string); // 支持自定义扩展
```

## 与现有 Naive UI 主题集成

项目 `apps/web-naive` 使用 Naive UI，主题系统通过 `@vben/common-ui` 的主题 CSS 变量层与 Naive UI 的 `themeOverrides` 配合：

- CSS 变量控制整体布局和通用组件的颜色
- Naive UI 的主题配置通过适配器文件 `src/adapter/naive.ts` 处理
