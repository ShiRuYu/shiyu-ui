# 本地开发

> 官方文档：https://doc.vben.pro/guide/essentials/development.html

## 前置准备

### 基础知识要求

- Vue 3 / Composition API
- Tailwind CSS
- TypeScript
- Vue Router
- Vite
- Pnpm
- Turbo（Monorepo 任务编排）

### 推荐 VSCode 插件

| 插件                      | 用途                 |
| ------------------------- | -------------------- |
| Vue - Official            | Vue 官方插件（必装） |
| Tailwind CSS IntelliSense | Tailwindcss 提示     |
| CSS Variable Autocomplete | CSS 变量提示         |
| Iconify IntelliSense      | 图标预览             |
| i18n Ally                 | 国际化               |
| ESLint                    | 代码检查             |
| Oxc                       | Oxlint / Oxfmt 集成  |
| Stylelint                 | CSS 格式检查         |
| DotENV                    | .env 文件高亮        |

## 本地运行项目

```bash
# 选择应用运行（交互式选择）
pnpm dev

# 直接启动 web-naive（本项目）
pnpm dev:naive

# 启动其他应用
pnpm dev:antd        # Ant Design Vue 版本
pnpm dev:ele         # Element Plus 版本
pnpm dev:tdesign     # TDesign 版本
pnpm dev:docs        # 文档
```

## Npm Scripts 速查

| 命令               | 说明                               |
| ------------------ | ---------------------------------- |
| `pnpm dev`         | 启动项目（可选应用）               |
| `pnpm dev:naive`   | 启动 web-naive 应用                |
| `pnpm build`       | 构建所有应用                       |
| `pnpm build:naive` | 仅构建 web-naive                   |
| `pnpm preview`     | 预览构建结果                       |
| `pnpm lint`        | Lint 代码检查                      |
| `pnpm format`      | 格式化代码                         |
| `pnpm check`       | 全量检查（循环引用、类型、拼写等） |
| `pnpm test:unit`   | 运行单元测试                       |
| `pnpm test:e2e`    | 运行 E2E 测试                      |
| `pnpm clean`       | 清理 node_modules/dist/.turbo      |
| `pnpm reinstall`   | 删除锁文件并重新安装               |
| `pnpm commit`      | 规范化提交（czg）                  |

## 区分构建环境

以给 `web-naive` 添加测试环境 `test` 为例：

**1. `apps/web-naive/package.json`**

```json
"scripts": {
  "build:prod": "pnpm vite build --mode production",
  "build:test": "pnpm vite build --mode test",
  "dev": "pnpm vite --mode development"
}
```

**2. 根目录 `package.json`**

```json
"build:naive": "pnpm run build --filter=@vben/web-naive",
"build-test:naive": "pnpm run build --filter=@vben/web-naive build:test"
```

**3. `turbo.json`**

```json
"build-test:naive": {
  "dependsOn": ["@vben/web-naive#build:test"],
  "outputs": ["dist/**"]
}
```

## 公共静态资源

需要通过 `src="/xxx.png"` 直接引入的静态资源（图片、静态 HTML 等），需放在对应项目的 `public/static/` 目录下。引入路径为 `src="/static/xxx.png"`。

## Vue DevTools

开发环境内置了 Vue DevTools，默认关闭，可在 `.env.development` 中开启：

```bash
VITE_DEVTOOLS=true
```

## 依赖问题排查

如遇依赖相关问题，可尝试重新安装依赖：

```bash
# 删除所有 node_modules、锁文件，重新安装
pnpm reinstall
```
