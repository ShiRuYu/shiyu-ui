## 后端契约

后端仓库 `shiyu-ai/docs/文档导航.md` 提供 API 接口参考、领域数据字典、菜单权限矩阵、错误码、安全审计、部署运维和本轮质量联调报告。具体数量以文档校验命令的当前输出为准。前端提交前运行 `pnpm run test:contract`，确保本地 API 调用与保存的 OpenAPI 快照一致。

跨仓库模块依赖、前后端调用链、领域功能和核心业务旅程见后端仓库的 `shiyu-ai/docs/系统全景与模块调用.md`；接口逐条参数仍以 OpenAPI 和后端 API 接口参考为准。
