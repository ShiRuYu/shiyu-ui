## 第一章：环境搭建与启动

### 1.1 环境要求

| 工具 | 版本 | 检查命令 |
|------|------|---------|
| Node.js | ≥ 18.x（推荐 v20 LTS） | `node -v` |
| pnpm | ≥ 9.x | `pnpm -v` |

### 1.2 启动项目

**第一步：安装依赖**

```bash
cd shiyu-ui
pnpm install
```

> ⚠️ 必须使用 pnpm，不要用 npm 或 yarn。

**第二步：启动开发服务器**

```bash
cd apps/web-naive
pnpm dev
```

成功日志：
```
➜  Local:   http://localhost:5888/
```

**第三步：确认后端已启动**

前端依赖后端 API，启动前请确认后端已在 `http://localhost:9000` 运行。

## 第二章：登录与角色选择

### 2.1 访问登录页

浏览器打开 `http://localhost:5888/`，进入登录页面。

### 2.2 使用默认账号登录

| 角色 | 用户名 | 密码 | 说明 |
|------|--------|------|------|
| 超级管理员 | vben | admin123 | 拥有全部权限，可管理系统和查看所有数据 |
| 管理员 | admin | admin123 | 同 super，具备全功能权限 |
| 普通用户 | jack | admin123 | 仅智能体和知识库权限 |

> 不同角色登录后看到的左侧菜单不同。

### 2.3 登录后的主界面

登录成功后进入**仪表盘**页面，左侧菜单栏结构：

```
仪表盘                        ← 默认首页
教育中心                      ← 主要业务入口（学生/老师）
日常记录
智能体
知识库管理
文件管理
系统管理                      ← 仅管理员可见
```

### 2.4 切换角色（开发调试用）

如果需要以其他角色身份操作（如 teacher/student/parent），需要在系统管理的用户管理中创建新用户并分配角色，重新登录。

## 第三章：系统管理（管理员前置准备）

> **前置条件：** 以 vben 或 admin 账号登录。

### 3.1 工作空间管理

**入口：** 左侧菜单 → 系统管理 → 工作空间管理（`/system/workspace`）

**操作步骤：**
1. 查看已存在的工作空间树（总公司 → 技术部/产品部 → 前端组/后端组）
2. 点击"新增"创建新的工作空间
3. 输入名称、选择父级空间
4. 点击确认

> **为什么需要？** 用户和角色必须关联到工作空间，否则无法分配权限。

### 3.2 用户管理

**入口：** 左侧菜单 → 系统管理 → 用户管理（`/system/user`）

**操作步骤：**

1. **查看用户列表**：系统已有 vben、admin、jack 三个默认用户
2. **新增用户**（如创建学生账号）：
   - 点击"新增用户"按钮
   - 填写用户名、昵称、密码
   - 选择所属租户（默认租户）
   - 点击保存
3. **分配角色**：
   - 在用户列表中点击"分配角色"
   - 选择角色（student / teacher / parent）
   - 选择工作空间
   - 点击确认
4. **起用/停用**：点击状态开关控制用户是否可登录

### 3.3 角色管理

**入口：** 左侧菜单 → 系统管理 → 角色管理（`/system/role`）

**操作步骤：**
1. 查看系统预置角色：super、admin、user、teacher、student、parent
2. **新建角色**（如有需要）：
   - 点击"新增"
   - 输入角色编码和名称
   - 保存
3. **分配菜单权限**：
   - 点击角色的"菜单权限"按钮
   - 勾选该角色可访问的菜单树
   - 提交保存

### 3.4 菜单管理

**入口：** 左侧菜单 → 系统管理 → 菜单管理（`/system/menu`）

**操作步骤：**
1. 查看完整的菜单树结构
2. 可新增/编辑/删除菜单项
3. 菜单管理影响左侧导航栏的显示

### 3.5 字典管理

**入口：** 左侧菜单 → 系统管理 → 字典管理（`/system/dict`）

管理系统中使用的字典数据（如学科分类、题目类型等）。

## 第四章：知识库管理（前置准备）

> **前置条件：** 以 vben、admin 或 teacher 角色登录。

### 4.1 知识点管理

**入口：** 左侧菜单 → 知识库管理 → 知识点管理（`/knowledge/list`）

**操作步骤：**

**第一步：创建知识点分类**
1. 点击"新增"
2. 输入知识点名称（如"一元二次方程"）
3. 选择所属学科（需先在教育管理中创建学科）
4. 选择难度等级
5. 填写内容描述
6. 保存

**第二步：建立知识关系**
1. 进入知识点详情
2. 点击"关联知识点"
3. 选择关系类型（前置知识/后续知识/相关知识）
4. 选择目标知识点
5. 保存

> **为什么需要？** 知识点关系是学习路径规划和 AI 讲解的基础。

### 4.2 知识图谱

**入口：** 左侧菜单 → 知识库管理 → 知识图谱（`/knowledge/graph`）

可视化查看知识点的 DAG 关系图，支持拖拽、缩放、点击节点查看详情。

### 4.3 文档管理

**入口：** 左侧菜单 → 知识库管理 → 文档管理（`/knowledge/document`）

上传和管理知识点相关的文档资源（PDF、Word、图片等）。

### 4.4 索引管理

**入口：** 左侧菜单 → 知识库管理 → 索引管理（`/knowledge/index`）

管理知识库的检索索引，支持重建索引操作。

## 第五章：教育管理（教师/管理员前置准备）

> **前置条件：** 以 vben、admin 或 teacher 角色登录。
> 点击左侧菜单"教育中心"→ 选择"管理"分组卡片页。

### 5.1 学科管理

**入口：** 教育中心 → 管理 → 学科管理（`/edu/subject`）

**操作步骤：**
1. 点击"新增学科"
2. 输入学科名称（如"数学"、"语文"、"英语"）
3. 选择学段（小学/初中/高中）
4. 点击保存

> **为什么需要？** 学科是课程、教材、题目的顶层分类，必须先创建。

### 5.2 教材管理

**入口：** 教育中心 → 管理 → 教材管理（`/edu/textbook`）

**操作步骤：**
1. 点击"新增教材"
2. 选择所属学科
3. 输入教材名称（如"人教版七年级数学上册"）
4. 选择年级
5. 保存

### 5.3 章节管理

**入口：** 教育中心 → 管理 → 章节管理（`/edu/chapter`）

**操作步骤：**
1. 选择教材
2. 点击"新增章节"创建树形结构
3. 输入章节名称（如"第一章 有理数"）
4. 设置层级（章→节→小节）
5. 保存

### 5.4 课程管理

**入口：** 教育中心 → 管理 → 课程管理（`/edu/course`）

**操作步骤：**
1. 点击"新增课程"
2. 选择学科、教材、章节
3. 输入课程名称、描述
4. 关联知识点（从知识库中选择）
5. 设置课时和排序
6. 保存

### 5.5 题库管理

**入口：** 教育中心 → 管理 → 题库管理（`/edu/question`）

**操作步骤：**
1. 点击"新增题目"
2. 选择题型（选择题/填空题/解答题/判断题）
3. 选择学科、教材、章节
4. 关联知识点
5. 设置难度（1-5 级）
6. 输入题目内容、选项（选择题）、答案
7. 保存

### 5.6 考试管理

**入口：** 教育中心 → 管理 → 考试管理（`/edu/exam`）

**操作步骤：**
1. 点击"新增考试"
2. 输入考试名称
3. 选择学科
4. 从题库中选择题目
5. 设置考试时长、总分
6. 发布考试

### 5.7 学习计划管理

**入口：** 教育中心 → 管理 → 学习计划（`/edu/plan`）

管理学生的学习计划，包括计划名称、时间范围、学习内容等。

### 5.8 复习任务管理

**入口：** 教育中心 → 管理 → 复习任务（`/edu/review`）

管理艾宾浩斯复习任务，配置复习周期、复习内容等。

### 5.9 学情分析

**入口：** 教育中心 → 管理 → 学情分析（`/edu/analytics`）

查看学生学习情况的统计看板，包括完成率、正确率等。

### 5.10 资源管理

**入口：** 教育中心 → 管理 → 资源管理（`/edu/resource`）

管理教学资源文件（课件、教案等）。

### 5.11 错题管理

**入口：** 教育中心 → 管理 → 错题管理（`/edu/wrong-question`）

查看和管理学生的错题数据，支持按学科、知识点筛选。

## 第六章：学生学习流程

> **前置条件：**
> 1. 管理员已创建学科、教材、章节（第五章）
> 2. 教师已创建课程、题库（第五章）
> 3. 学生账号已创建并分配 student 角色

### 6.1 进入教育中心

**入口：** 左侧菜单 → 教育中心

进入后看到 7 个卡片分组，**学生角色只能看到前 6 个**（不含"管理"）。

### 6.2 学习模块

**操作步骤：**
1. 在教育中心首页点击"**学习**"分组卡片
2. 进入学习卡片页，有 4 个功能卡片：
   - **课程学习** → `/learning/course`
   - **知识浏览** → `/learning/knowledge`
   - **学习计划** → `/learning/plan`
   - **学习资源** → `/learning/resource`

#### 6.2.1 课程学习

**入口：** 学习卡片 → 课程学习（`/learning/course`）

**操作步骤：**
1. 查看课程列表（可按学科、年级筛选）
2. 点击课程卡片进入课程详情
3. 查看课程章节结构
4. 点击"开始学习"进入学习页面
5. 学习完成后系统自动记录学习进度

#### 6.2.2 知识浏览

**入口：** 学习卡片 → 知识浏览（`/learning/knowledge`）

**操作步骤：**
1. 查看知识点列表（可按学科筛选）
2. 搜索知识点
3. 点击知识点查看详情（包含知识点内容、关联关系、相关题目）

#### 6.2.3 学习计划

**入口：** 学习卡片 → 学习计划（`/learning/plan`）

**操作步骤：**
1. 查看个人学习计划列表
2. 点击计划查看每日任务
3. 完成任务后标记"已完成"

#### 6.2.4 学习资源

**入口：** 学习卡片 → 学习资源（`/learning/resource`）

浏览教师分享的学习资源文件。

### 6.3 练习模块

**入口：** 教育中心 → 练习卡片

练习模块包含 2 个功能：

#### 6.3.1 题库练习

**入口：** 练习卡片 → 题库练习（`/practice/question`）

**操作步骤：**
1. 选择学科、年级、章节
2. 选择难度（可选）
3. 点击"开始练习"
4. 逐题作答
5. 提交后查看对错和解析
6. 系统自动记录错题

#### 6.3.2 错题本

**入口：** 练习卡片 → 错题本（`/practice/wrong`）

**操作步骤：**
1. 查看所有历史错题（按学科分组）
2. 点击"重新练习"重做错题
3. 做对的题目可移出错题本
4. 查看错题统计

### 6.4 考试模块

**入口：** 教育中心 → 考试卡片

#### 6.4.1 在线考试

**入口：** 考试卡片 → 在线考试（`/exam/list`）

**操作步骤：**
1. 查看可参加的考试列表
2. 点击"参加考试"
3. 在规定时间内完成答题
4. 点击"交卷"
5. 查看考试结果和答案解析

#### 6.4.2 AI 组卷

**入口：** 考试卡片 → AI 组卷（`/exam/ai-exam`）

**操作步骤：**
1. 选择学科、知识点范围
2. 设置题目数量和难度
3. 点击"AI 生成试卷"
4. AI 自动生成个性化试卷
5. 在线作答
6. AI 自动批改并给出评分

## 第七章：复习中心（艾宾浩斯）

**入口：** 教育中心 → 复习卡片

### 7.1 今日复习

**入口：** 复习卡片 → 今日复习（`/review/today`）

**操作步骤：**
1. 查看今日需要复习的知识点列表
2. 系统基于艾宾浩斯遗忘曲线自动生成复习计划
3. 复习周期：1 天 → 3 天 → 7 天 → 15 天 → 30 天 → 90 天
4. 点击知识点查看详细内容
5. 完成后标记"已复习"

### 7.2 复习历史

**入口：** 复习卡片 → 复习历史（`/review/history`）

查看历史复习记录、复习完成情况统计。

**入口：** 数据卡片 → 薄弱分析（`/analytics-center/weak`）
