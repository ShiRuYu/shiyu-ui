### 1.4 命名与风格一致性

| 类别 | 问题 |
|------|------|
| **函数后缀** | Core 和 Knowledge 模块用 `Api` 后缀（`loginApi`, `getKnowledgeListApi`），其他模块不用 |
| **HTTP 方法** | System 模块用 PATCH 更新，Education/Knowledge 模块用 PUT 更新 |
| **Record 模块签名** | 更新函数有的传 id（`updateRole(id, data)`），有的传完整对象（`updateMedia(data)`） |
| **类型安全** | Knowledge 模块大量使用 `any` 类型 |
| **命名风格** | `upload_file` 使用 snake_case |

### 1.5 Request 客户端配置

- **`requestClient`**: 带 auth 拦截器，`responseReturn: 'data'` 自动解包
- **`baseRequestClient`**: 无拦截器，用于 refresh/logout 等免认证操作
- **Token 刷新**: `enableRefreshToken: false`（默认关闭）
- **错误处理**: `errorMessageResponseInterceptor` 对业务错误码和网络错误分别处理

## 第三部分：Vben5 框架使用分析

### 3.1 已充分利用的功能

| 功能 | 使用情况 |
|------|----------|
| `useVbenForm` | 所有 CRUD 模态框使用 ✅ |
| `useVbenModal` | 所有弹窗编辑使用 ✅ |
| `useVbenVxeGrid` | 所有数据表格使用 ✅ |
| `Page` 组件 | 所有页面布局使用 ✅ |
| `useUserStore` / `useAccessStore` | 认证/路由使用 ✅ |

### 3.2 完全未使用的框架能力

| 功能 | 适用场景 | 优先级 |
|------|----------|--------|
| **`v-access` 权限指令** | 按钮级权限控制（已注册但零使用） | P1 |
| **`useVbenDrawer`** | Agent 编辑页面用抽屉替代路由跳转 | P2 |
| **`useTabs`** | 标签页管理 | P2 |
| **`to()` async 模式** | 统一错误处理替代 try/catch | P2 |
| **`downloadFile*` 工具集** | 文件下载功能 | P2 |
| **VbenForm 内置 action 按钮** | 所有表单设 `showDefaultActions: false` 未用 | P3 |
| **VbenForm `collapsible`** | 搜索表单折叠展开 | P3 |
| **shadcn-ui 封装组件** | 应用直接使用 NaiveUI 绕过 Vben 主题层 | P3 |

### 3.3 重复模式（应抽取为 composable）

| 模式 | 重复次数 | 建议抽取 |
|------|---------|----------|
| 删除确认 + loading + 刷新 | 50+ 处 | `useDeleteConfirm()` |
| 表单模态框提交逻辑 | 30+ 处 | `useCrudFormModal()` |
| `refreshGrid = () => gridApi.query()` | 40+ 处 | `useGridRefresh()` |
| 搜索表单空值过滤 | 10+ 处 | 工具函数 `cleanParams()` |
| status 类型转换 | 10+ 处 | API 层统一处理 |

### 3.4 i18n 使用不一致

- 95 个视图从 `#/locales` 导入 `$t`
- 4 个认证视图从 `@vben/locales` 导入 `$t`
- Agent 模块、File 模块、Dashboard 页面大量硬编码中文未使用 `$t`
- Knowledge Relation 页面标题硬编码 `'知识关系'`
