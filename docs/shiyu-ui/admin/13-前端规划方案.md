# Web-Naive 前端详细规划方案

> 最后更新：2026-07-02 基于 shiyu-ai 后端 14 模块 + docs 文档全量分析参照 shiyu-ui 现有组件模式 (VxeGrid CRUD / VbenModal / VbenForm)

---

## 1. 差距分析

### 1.1 后端模块 vs 前端页面覆盖度

| 后端模块 | 已有前端页面 | 缺失前端页面 |
| --- | --- | --- |
| `shiyu-ai-auth` | 登录/注册/用户/角色/菜单/租户/工作空间 | - |
| `shiyu-ai-education` | **无** | 学科/教材/章节/课程/题库/考试/复习/计划/错题本/资源/学生 |
| `shiyu-ai-knowledge` | **无** | 知识点CRUD/知识图谱可视化/学习路径/文档管理/索引重建 |
| `shiyu-ai-agent` (教育Agent) | Agent管理/通用Chat | Teacher/Practice/Exam/Review/Planner/Report 专用界面 |
| `shiyu-ai-analytics` | 通用Dashboard | 能力雷达/薄弱点/学习趋势/成长档案 |
| `shiyu-ai-record` | 记录/人物/时间线/标签/媒体 | - |
| `shiyu-ai-core/model` | AI平台/AI模型/Chat | - |

### 1.2 结论

前端仅覆盖后端约 **30%** 的功能，教育核心域完全缺失。

### 5.1 `api/education/subject.ts`

```typescript
import { requestClient } from '#/api/request';

export namespace EducationSubjectApi {
  export interface Subject {
    [key: string]: any;
    id: number;
    code: string;
    name: string;
    gradeLevel: string;
    icon: string;
    sortOrder: number;
  }
}

async function getSubjectList() {
  return requestClient.get<EducationSubjectApi.Subject[]>('/api/v1/subject');
}

async function getSubjectById(id: number) {
  return requestClient.get<EducationSubjectApi.Subject>(
    `/api/v1/subject/${id}`,
  );
}

async function getSubjectByCode(code: string) {
  return requestClient.get<EducationSubjectApi.Subject>(
    `/api/v1/subject/code/${code}`,
  );
}

async function getSubjectByGradeLevel(gradeLevel: string) {
  return requestClient.get<EducationSubjectApi.Subject[]>(
    `/api/v1/subject/grade-level/${gradeLevel}`,
  );
}

async function createSubject(data: Omit<EducationSubjectApi.Subject, 'id'>) {
  return requestClient.post('/api/v1/subject', data);
}

async function updateSubject(
  id: number,
  data: Partial<EducationSubjectApi.Subject>,
) {
  return requestClient.put(`/api/v1/subject/${id}`, data);
}

async function deleteSubject(id: number) {
  return requestClient.delete(`/api/v1/subject/${id}`);
}

export {
  createSubject,
  deleteSubject,
  getSubjectByCode,
  getSubjectByGradeLevel,
  getSubjectById,
  getSubjectList,
  updateSubject,
};
```

```typescript
async function teachStream(
  data: EducationAgentApi.TeachRequest,
  onMessage: (chunk: string) => void,
): Promise<void> {
  const accessStore = useAccessStore();
  const token = accessStore.accessToken;
  const baseURL = requestClient.getBaseUrl() ?? '';
  const response = await fetch(`${baseURL}/api/v1/agent/teacher`, {
    body: JSON.stringify({ ...data, stream: true }),
    headers: {
      Accept: 'text/event-stream',
      Authorization: token ? `Bearer ${token}` : '',
      'Content-Type': 'application/json',
    },
    method: 'POST',
  });
  if (!response.ok || !response.body)
    throw new Error(`Stream error: ${response.status}`);
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    onMessage(decoder.decode(value, { stream: true }));
  }
}
```

## 6. 页面组件详细设计

### 6.1 标准 CRUD 页面 (三文件模式)

每个 CRUD 页面由 3 个文件组成：

```
views/<module>/<entity>/
  list.vue          -- 主列表页 (VxeGrid)
  data.ts           -- 列定义 + 表单 Schema
  modules/
    form.vue        -- 弹窗表单 (VbenModal)
```

### 6.2 教育域 CRUD 页面清单

#### 6.2.1 学科管理 `views/education-admin/subject/`

**文件结构:**

```
subject/
  list.vue
  data.ts
  modules/form.vue
```

**data.ts 列定义:**

```
columns: id(80) | code(120) | name(150) | gradeLevel(120) | icon(80) | sortOrder(80) | operation(150)
searchSchema: name(Input) | gradeLevel(Select: K0/K1/K2/K3)
formSchema: code(Input,required) | name(Input,required) | gradeLevel(Select,required) | icon(Input) | sortOrder(InputNumber)
```

```
searchSchema: name(Input) | subjectCode(ApiSelect: getSubjectList) | grade(InputNumber)
formSchema: name(Input,required) | subjectCode(ApiSelect,required) | grade(InputNumber,required) | publisher(Input) | isbn(Input)
```

## 10. 技术约定

### 10.1 组件模式选择

| 页面类型       | 模式                 | 参考                                 |
| -------------- | -------------------- | ------------------------------------ |
| 标准 CRUD 列表 | VxeGrid + Modal Form | `views/system/user/`                 |
| 卡片列表       | NGrid + NCard        | `views/agent/admin/agent-list.vue`   |
| 详情/编辑页    | 路由页面 + NLayout   | `views/agent/admin/agent-edit.vue`   |
| 聊天界面       | SSE + Markdown       | `views/agent/agent/modules/chat.vue` |
| 图表页面       | ECharts              | `views/dashboard/analytics/`         |
| 答题界面       | 自定义表单           | 新建                                 |

### 10.2 API 调用规范

- 使用 `requestClient` from `#/api/request`
- 分页参数映射: 前端 `page`/`pageSize` → 后端 `pageNo`/`pageSize`
- SSE 流式: 使用原生 `fetch` + `ReadableStream`
- 类型定义: `export namespace XxxApi { ... }`
- 导出: 底部 `export { ... }` 按字母序

### 10.3 状态管理

- 当前学生ID: 从 `useUserStore().userInfo.studentId` 获取
- 当前学科/年级筛选: 页面级 `ref`，不需要全局 store
- AI对话历史: 页面级 `ref`，不需要持久化

### 10.4 图表依赖

- ECharts 已通过 `@vben/plugins/echarts` 集成
- 使用 `useECharts` composable 初始化图表
- 雷达图: `type: 'radar'`
- 折线图: `type: 'line'`
- 知识图谱: `type: 'graph'`, `layout: 'force'`
